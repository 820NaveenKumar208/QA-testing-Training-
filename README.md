# Amazon Website Testing 

##  Project Overview

This project is part of my QA Testing learning journey.

The objective is to practice **Manual Testing** by testing different functionalities of an e-commerce website such as Amazon.

##  Testing Objective

To understand and practice:

- Test Case Creation
- Test Execution
- Functional Testing
- Defect Identification
- Pass/Fail Analysis
- Test Execution Summary

##  Application Tested

**Application:** Amazon Website  
**Testing Type:** Manual Testing  
**Browser:** Google Chrome  
**Device:** Laptop/Desktop

##  Testing Scope

The following modules were tested:

- Homepage
- Search
- Product
- Cart
- Account
- Filters
- Navigation
- Checkout

## 🧪 Test Execution

A total of **15 test cases** were executed.

| Metric | Result |
|---|---:|
| Total Test Cases | 15 |
| Passed | 13 |
| Failed | 2 |
| Not Executed | 0 |
| Blocked | 0 |
| Pass Rate | 87% |

##  Defects Identified

### DEF001
**Test Case:** TC010  
**Module:** Account  
**Issue:** Account creation failed when the email already existed.  
**Severity:** Medium  
**Status:** Open

### DEF002
**Test Case:** TC015  
**Module:** Checkout  
**Issue:** Checkout required sign-in before proceeding to the address page.  
**Severity:** Low  
**Status:** Open
